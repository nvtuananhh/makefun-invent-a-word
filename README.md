## What it does

`main.py` (Python 3, standard library only, no network) writes one
newly coined English word with its one-line definition to
`/output/entry.txt`:

> Chairdrobe (n.): the chair where clothes too dirty for the closet but too clean for the wash wait out their fate.

The line is 113 characters long. It lands on the judge's
brief: a freshly invented word naming a real gap every reader
recognises at once — the chair where in-between clothes live.
The word is well formed by analogy (like floordrobe, the floor
version): chair + wardrobe, sayable, spellable, memorable,
sounding as though English could have grown it. The definition
is exact and self-contained, landing in one reading, and the
twist arrives at the last word: fate.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (113 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
